# Что такое OSINT

**OSINT (Open Source Intelligence)** — это сбор, обработка и анализ информации из открытых источников.

В отличие от закрытых баз данных или несанкционированного доступа к системам, классический OSINT предполагает работу с информацией, которая доступна в интернете или других открытых источниках.

В качестве исходных данных могут использоваться:

- имя и фамилия;
- username;
- номер телефона;
- адрес электронной почты;
- фотография;
- Telegram ID;
- ссылка на профиль;
- название компании;
- автомобильный номер;
- VIN;
- домен;
- IP-адрес;
- название Telegram-канала;
- название группы;
- другие публичные идентификаторы.

OSINT используется журналистами, специалистами по кибербезопасности, исследователями, аналитиками и обычными пользователями, которым требуется проверить определённую информацию.

# Как работают OSINT-боты в Telegram

Telegram удобен для OSINT благодаря большому количеству публичных каналов, групп, профилей и сообщений.

Специализированный бот может принимать определённый идентификатор и выполнять поиск по доступным ему источникам.

Например, исходными данными может быть:

```text
username
```

или:

```text
номер телефона
```

или:

```text
VIN автомобиля
```

После этого сервис возвращает найденные сведения, если они имеются в доступных ему источниках.

Важно понимать, что **разные OSINT-боты используют разные источники и базы**, поэтому два сервиса могут показать совершенно разные результаты.

# 🧩 Как правильно проводить OSINT-поиск

Хороший OSINT-поиск обычно начинается не с большого количества случайных запросов, а с одного или нескольких исходных идентификаторов.

Например:

```text
username → поиск профилей → поиск Telegram → проверка связей → независимое подтверждение
```

Или:

```text
телефон → поиск открытых упоминаний → проверка профилей → сопоставление данных
```

Для автомобиля:

```text
VIN → поиск сведений → проверка истории → сравнение с объявлением
```

Главная задача — не просто получить как можно больше результатов, а **понять, какие из них действительно относятся к исследуемому объекту**.

# 🔗 Сопоставление нескольких источников

Одна из главных ошибок начинающего OSINT-исследователя — доверять первому найденному совпадению.

Допустим, найден профиль с определённым username.

Это ещё не означает, что профиль принадлежит нужному человеку.

Для повышения достоверности можно сравнить:

- username;
- фотографию;
- имя;
- город;
- публичные контакты;
- дату активности;
- связанные аккаунты;
- открытые публикации.

Чем больше независимых признаков совпадает, тем больше информации появляется для дальнейшей проверки.

Полученные данные необходимо:

1. найти;
2. сохранить;
3. проверить;
4. сопоставить;
5. классифицировать;
6. подтвердить независимым источником.

Например, один сервис показывает определённое имя для номера телефона. Это ещё не означает, что найденное имя является достоверным.

Если аналогичные сведения подтверждаются несколькими независимыми источниками, их можно рассматривать как более надёжный результат.

# ⚠️ Ограничения OSINT-инструментов

Ни один сервис не гарантирует, что найденная информация будет полной.

Причины могут быть разные:

- информация удалена;
- профиль закрыт;
- данные устарели;
- сервис не имеет нужного источника;
- произошла ошибка сопоставления;
- один идентификатор используется несколькими людьми;
- информация никогда не публиковалась открыто.

Поэтому отсутствие результата также не означает отсутствие человека, аккаунта или информации.
